🎯 YOUR 3-STEP QUICK START
══════════════════════════════════════════════════════════════════════════════

✅ STEP 1: SETUP PROJECT (1 minute)
─────────────────────────────────────────────────────────────────────────────
Run this command in your terminal:

    ./setup.sh

This will:
  ✓ Create Go modules
  ✓ Install npm dependencies
  ✓ Prepare environment files


✅ STEP 2: START BACKEND (Terminal 1)
─────────────────────────────────────────────────────────────────────────────
Open NEW terminal, run:

    cd backend
    go run ./cmd

You should see:
  ✓ "Database initialized successfully"
  ✓ "Server running on port 8080"

Keep this terminal OPEN!


✅ STEP 3: START FRONTEND (Terminal 2)
─────────────────────────────────────────────────────────────────────────────
Open ANOTHER NEW terminal, run:

    cd frontend
    npm run dev

You should see:
  ✓ "VITE v5.0.8 ready in 500 ms"
  ✓ Local: http://localhost:3000/

Keep this terminal OPEN!


🌐 OPEN YOUR BROWSER
═════════════════════════════════════════════════════════════════════════════

Go to: http://localhost:3000

You should see the login page!


🔐 FIRST LOGIN (AS ADMIN)

📋 ADMIN CHECKLIST
═════════════════════════════════════════════════════════════════════════════

After login, follow these steps:

1. CREATE CANDIDATES (Do this first!)
   ─────────────────────────────────────
   □ Click "Kandidat" tab
   □ Enter candidate names & numbers (1-7)
   □ Create exactly 7 candidates
   □ Example: Budi Santoso #1, Siti #2, etc.

2. GENERATE VOTER ACCOUNTS
   ─────────────────────────────────────
   □ Click "Generate Akun" tab
   □ Enter count (e.g., 300)
   □ Click "Generate"
   □ COPY the credentials (username & password)
   □ Save to Excel/CSV for distribution
   ⚠️  You won't be able to see them again!

3. START VOTING PERIOD 1 (KETUA)
   ─────────────────────────────────────
   □ Go to "Dashboard" tab
   □ Find "KETUA" card
   □ Click "Buka" button
   □ Status changes to "🔴 TERBUKA"
   ✅ Voters can now start voting for Ketua!

4. DISTRIBUTE VOTER CREDENTIALS
   ─────────────────────────────────────
   □ Give username & password to each voter
   □ Voters can login at http://localhost:3000
   □ Select "Pemilih" and login
   □ They will see the KETUA voting screen

5. MONITOR VOTING IN REAL-TIME
   ─────────────────────────────────────
   □ Stay in Dashboard tab
   □ Refresh page (F5) to see updates
   □ Watch "Sudah Memilih" count increase

6. CLOSE PERIOD & DETERMINE WINNER
   ─────────────────────────────────────
   □ When voting complete, click "Tutup" on KETUA
   □ Status changes to "🔵 TERTUTUP"
   □ System automatically finds winner (most votes)
   □ Winner is automatically removed from next period!

7. REPEAT FOR OTHER POSITIONS
   ─────────────────────────────────────
   □ Period 2: SEKRETARIS (6 candidates left)
   □ Period 3: BENDAHARA (5 candidates left)
   □ Period 4: PENGAWAS (4 candidates left)
   □ View final results in Dashboard

✅ VOTING COMPLETE! 🎉

🆘 QUICK TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Problem: "Cannot connect to server"
Solution: Make sure both backend & frontend are running!
          Check Step 2 & Step 3 above

Problem: "Blank page in browser"
Solution: Wait 10 seconds for app to load, refresh (F5)

Problem: "Port 8080 already in use"
Solution: Kill the process or change PORT in backend/.env

Problem: "npm command not found"
Solution: Install Node.js from https://nodejs.org/

Problem: "go command not found"
Solution: Install Go from https://golang.org/

More issues? → Check TROUBLESHOOTING.md
